# Information Theory & Data Compression Algorithms

A curated collection of data compression algorithms implemented as part of information theory exploration. This repository contains organized implementations of classic lossless compression techniques.

---

## 📁 Repository Structure

The repository is organized into individual project folders, each dedicated to a specific compression algorithm:

```text
.
├── 01 - LZ 77 Algorithm/     # Implementation of LZ77 sliding window compression
├── 02 - Huffman's Algorithm/  # Implementation of Huffman coding algorithm
└── README.md                  # Main repository documentation
```

## Usage & Setup
### Clone the repository:

```
git clone [https://github.com/Abdo2000-1/Information-Theory-Data-Compression.git](https://github.com/Abdo2000-1/Information-Theory-Data-Compression.git)
cd Information-Theory-Data-Compression
```
