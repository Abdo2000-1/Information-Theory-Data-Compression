# LZ77 Data Compression

## Description
A Python implementation of the LZ77 compression algorithm that generates Tags in Binary format and supports decompression.

## Project Files
- `compressor.py`: Compresses the text from `file1.txt` and saves the Tags in `file2.txt`.
- `decompressor.py`: Reads the compressed Tags and saves the result in `decompressed.txt`.
- `main.py`: Provides a console menu to run the program.
- `file1.txt`: Original input text.
- `file2.txt`: Compressed Tags and Binary representation.
- `decompressed.txt`: Reconstructed text.

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

4. Follow the menu options to compress, decompress, view files, and verify the result.

## Requirements
- Python 3 or late
- No external libraries required.
